This Python script generates 100 random, evenly-distributed indices for the random selection of images to be used for manual analysis.
Practically, it selects 4 distinct image indices from groups of 24 images, 25 times, from the range [100, 700).
The result is 100 indices selected from 600 possible indices.

Note that the resulting indices are not in order.
The indices were imported to and sorted in an external spreadsheet program.
