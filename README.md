# sure-helper-programs
A few helper programs I coded to help with certain tasks in SUNY New Paltz SURE 2026 grant research.

Programs in order of use:
- **random-indices** - Used to generate a random, even distribution of image indices to use for manual evaluation.
- **image-viewer** - Used to streamline manual evaluation of images.
- **histogram** - Used to generate histograms from results of manual evaluation.

Each helper program's directory contains a Markdown file with more specific details about the program's purpose & usage.
