This is a simple Python app to facilitate manual counting of segmentation cases. It functions as follows:
- Images are read from the Select Results directory.
- Images are automatically cropped, layered, and scaled up for analysis.
- The user can place dots at the mouse's position for various cases, which are automatically counted, using A, S, D, and F.
- The user can quickly toggle between the unsegmented and segmented image using SPACE.
- The user can increase or decrease the image index by 1 using Q and E.
- The user can enter a specific image index to switch to.
- The user can click and drag the view of the image.

A few images have been included in the Select Results directory to allow a small demo.
